Local LLM Writing Assistant: one application built three ways

An offline assistant that drafts emails and corrects English grammar on a 4-bit quantized 4B-parameter model (qwen3.5:4b) through Ollama. I built it three times, with plain Ollama, LangChain and LangGraph, to compare what each framework adds.

This app runs entirely on your own computer, so there is no online version. Below are recorded runs, copied from each project's README and replayed here. They were recorded on an Intel Core i7-1165G7 laptop with 16 GB RAM and no GPU; the replay is faster than real time, and the real timings are shown.

Part 1: Plain Ollama Part 2: LangChain Part 3: LangGraph

LangGraph: a workflow that checks its own work

The email is drafted, reviewed by the model, fixed if needed, and then waits for a person to approve it. Grammar correction splits the text into sentences, corrects each one in its own parallel branch, and caches the results.
